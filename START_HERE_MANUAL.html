❤️ Bond Touch Prototype Manual

This is your complete founder guide for your smart long-distance touch bracelet prototype pair.

🌐 Is it a Local Server or a Cloud Server?

It is a GLOBAL CLOUD SERVER (Not Local!).

A "local server" only works inside your own apartment on your own home WiFi. If your partner goes outside or lives in another city, a local server stops working.

We built a Global Cloud Server for you on the internet. It runs 24/7 in the cloud. Whether you are on 4G mobile data in Rehab City or your partner is on WiFi in another country, both bracelets connect to this cloud server seamlessly!

📊 How to See & Manage Everything in Real-Time

You can inspect all touch signals passing through your Cloud Server live on your screen right now:

  • Live Relay Broker: Uses EMQX Cloud MQTT (Port 8084). It handles instant messages under 0.05 seconds.
  • Live Web Server: Hosted at https://band-beryl.vercel.app (Vercel Serverless Node.js backend).
  • Live Event Monitor: Open your instant test page anytime to inspect live signals!

🛠️ What to Do When Package Arrives Today

  1. Connect the wires: Plug ESP32 Pin D15 to Pushbutton, Pin D2 to Vibration Motor (+), and GND to (-).
  2. Plug ESP32 into Laptop: Use Micro-USB cable.
  3. Open Arduino IDE: Open file firmware/bracelet_firmware_esp32.ino, type your home WiFi name & password, and click Upload!
