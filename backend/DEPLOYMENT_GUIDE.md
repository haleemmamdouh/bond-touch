# Task 3: Backend Deployment & Firebase / Supabase Setup Guide

Step-by-step click-by-click instructions for setting up free backend hosting, Firebase push notifications, and Supabase database.

---

## Part 1: Firebase Project & Push Notifications (FCM) Setup

1. **Create Free Firebase Account:**
   - Go to [console.firebase.google.com](https://console.firebase.google.com) and sign in with any Google account.
   - Click **Add project** (إضافة مشروع).
   - Enter Project Name: `bond-touch-prototype` -> Click **Continue**.
   - Disable Google Analytics (optional, to keep it simple) -> Click **Create project**.

2. **Generate Service Account Credentials Key (For Backend):**
   - Click the ⚙️ Gear icon (Project Settings) at the top left.
   - Go to the **Service accounts** (حسابات الخدمة) tab.
   - Click **Generate new private key** (إنشاء مفتاح خاص جديد).
   - A `.json` file will download to your computer. Open this file in Notepad.
   - Copy the entire text inside the file. This is your `FIREBASE_SERVICE_ACCOUNT_JSON`.

---

## Part 2: Supabase Database Setup (Free)

1. **Create Supabase Account:**
   - Go to [supabase.com](https://supabase.com) and sign up for a free account.
   - Click **New project** -> Select Name `bond-touch-db` and create a database password.

2. **Create Devices Table:**
   - On the left sidebar, click **SQL Editor**.
   - Paste the following SQL script and click **Run**:

```sql
CREATE TABLE IF NOT EXISTS public.devices (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    pair_code TEXT NOT NULL,
    user_name TEXT NOT NULL,
    fcm_token TEXT NOT NULL,
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now()) NOT NULL,
    CONSTRAINT unique_pair_user UNIQUE (pair_code, user_name)
);
```

3. **Get Supabase Keys:**
   - Go to ⚙️ **Project Settings** -> **API**.
   - Copy **Project URL** (This is your `SUPABASE_URL`).
   - Copy **service_role secret key** (This is your `SUPABASE_SERVICE_ROLE_KEY`).

---

## Part 3: Deploy Backend Server to Railway.app (Free 1-Click Deploy)

1. **Sign Up on Railway:**
   - Go to [railway.app](https://railway.app) and sign up using GitHub or Email.

2. **Create New Project:**
   - Click **+ New Project** -> Select **Deploy from GitHub repo** (or drag & drop the `backend` folder).
   - Alternatively, use Railway CLI or Render.com web service.

3. **Add Environment Variables (Variables Tab):**
   - Add Variable: `PORT` = `3000`
   - Add Variable: `SUPABASE_URL` = *(Paste from Supabase API settings)*
   - Add Variable: `SUPABASE_SERVICE_ROLE_KEY` = *(Paste service_role key)*
   - Add Variable: `FIREBASE_SERVICE_ACCOUNT_JSON` = *(Paste single-line JSON string downloaded from Firebase)*

4. **Deploy & Copy Public URL:**
   - Railway will build and deploy the Node.js app automatically.
   - Click **Settings** -> **Generate Domain** (e.g. `https://bond-touch-production.up.railway.app`).
   - Test your deployment in browser: `https://bond-touch-production.up.railway.app/api/health`.
   - You should see: `{"status":"online", ...}`.
