⚡ ESP32-C3 SuperMini Wokwi Simulation Guide

1. Wokwi Quickstart Link

To view the visual diagram and run the simulation on Wokwi:

  1. Go to wokwi.com/projects/new/esp32-c3
  2. Click on the diagram.json tab in Wokwi and replace its content with the JSON below.
  3. Click on sketch.ino and paste the C++ code from bracelet_esp32_c3_supermini.ino.
  4. Hit Play (▶)!
